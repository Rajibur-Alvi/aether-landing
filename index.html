Common Questions

What file formats does Aether support? expand_more
Aether natively ingests CSV, JSON, Parquet, and Avro formats. We also provide SDKs for streaming raw byte telemetry from custom C++, Rust, and Python applications.
How is my data secured? expand_more
We are SOC 2 Type II compliant. All processing happens in-memory and is never persisted to disk unless explicitly requested. Data is encrypted in transit using TLS 1.3 and at rest using AES-256.
Can I export entropy heatmaps for reports? expand_more
Yes. You can export any visualization as a high-resolution PNG or PDF. We also support HTML embedding for live dashboards and raw JSON export of the entropy scores for custom tooling.
